# Crave design tokens

The platform uses one brand palette across the website and all four mobile applications.

| Token                   | Value     | Purpose                                  |
| ----------------------- | --------- | ---------------------------------------- |
| `--brand-primary`       | `#D9F447` | Primary Crave lime accent                |
| `--brand-primary-hover` | `#C4DE35` | Pressed and hover states                 |
| `--brand-primary-soft`  | `#EFF8B6` | Light accent surfaces                    |
| `--brand-ink`           | `#121815` | Dark text and brand background           |
| `--brand-forest`        | `#193B28` | Supporting green surface                 |
| `--semantic-success`    | `#22A861` | Completed and confirmed states           |
| `--semantic-warning`    | `#E4A22A` | Pending and attention states             |
| `--semantic-danger`     | `#D3515C` | Failed, cancelled and destructive states |
| `--semantic-info`       | `#3B82F6` | Processing and informational states      |

Main application text uses Inter. Display headings use Manrope. Operational identifiers use the
technical monospace stack. Layouts use the standard breakpoints 640px, 1024px and 1440px.
