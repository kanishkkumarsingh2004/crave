# Crave Admin app

This folder is the Capacitor Android/iOS shell for the existing React admin experience in
`app/admin`. It reuses the current dashboard and components instead of maintaining a second UI.
The WebView opens the deployed admin route with its own native app identity and deep-link scheme.
Links such as `craveadmin://admin/dashboard` open directly in the admin app.

The native app currently includes the operations dashboard, payment review, partner management,
CraveXP catalog management, settings, update checks, and native order/system notifications. The
custom audience notification composer is intentionally not part of the app; notifications are
generated by the normal order and update flows.

CraveXP product barcode scanning uses the device camera. Android declares the camera permission
and requests it when the scanner starts; if permission was previously denied, enable Camera for
Crave Admin in Android Settings before pressing **Try again**.

## Configure and sync

Use Node 22+, JDK 21, and an installed Android SDK (or Xcode on macOS). From the repository root:

```bash
pnpm install
cd admin_app
pnpm sync
```

The production server defaults to `https://crave.apexonestudio.com`. Open the projects with
`pnpm android` or, on macOS, `pnpm ios`. For an Android emulator, override the server with
`CAPACITOR_SERVER_URL=http://10.0.2.2:3000 pnpm sync` while the Next.js development server runs.

## Android APK

The current debug build is available here:

- [Download Crave Admin debug APK](../android-builds/crave-admin-debug.apk)

To rebuild and refresh the copied APK:

```bash
cd admin_app/android
./gradlew assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk ../../android-builds/crave-admin-debug.apk
```

The repository-level build copies the current APK to `android-builds/crave-admin-debug.apk` and
refreshes `android-builds/version.json` and `android-builds/SHA256SUMS.txt`.
